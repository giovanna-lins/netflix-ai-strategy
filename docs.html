🎬 CineMatch

A grounded personalized-discovery prototype — classroom MVP guide

What this is

CineMatch is a small, local demo of how a streaming service could turn member data into a personalized, governed home screen: rank titles for a member, write a tailored one-line description, check that each title is actually allowed to be shown to that member, and learn from what they click — all visible on one screen.

It is a teaching prototype built for a 90-minute classroom exercise, not production software. All members and titles are fictional; no real Netflix data is used.

🚀 Launch it (already set up)

source venv/bin/activate
streamlit run app.py

Opens at http://localhost:8501. Press Ctrl+C in the terminal to stop it. Presenting to the class? See DEMO_SCRIPT.md in the project folder for a ready-to-read 2–3 minute walkthrough.

First-time setup (only if starting from scratch)

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python generate_data.py
streamlit run app.py

Works fully offline with template taglines if there's no API key — see README.md for how to add one.

The flow

→

→
COMPOSEpick the top scorers
→
GENERATEAI tagline per title
→
GROUNDcheck territory / rating / policy
→
SERVEcleared titles shown; flagged → review
FEEDBACKa Play click nudges genre weights
↺

...loops back into RANK, closing the data flywheel on screen.

Using the app

  • Choose a member from the dropdown — each has a segment, home territory, favorite genres, and a maturity ceiling.
  • The Top picks row shows the highest-scoring titles that passed every check, each with a tagline and a score breakdown.
  • Example card:
    Crimson Ledger Thriller | Drama · Rated R
    "A thriller pick made for bingers fans like Ana."
  • The Needs review area shows titles that ranked well but failed a check (wrong territory, rating too high, closed rights window, or a restricted genre), with the plain-language reason.
  • Click 🎨 Generate art on a card to replace its colored style card with a live, abstract Gemini-generated illustration matched to the title's mood — this is opt-in per title since image generation is slower than the text taglines.
  • Click ▶ Play on any cleared title — it's logged, and its genres get a small ranking boost for the rest of your session. Reopen the ranking weights or just look again: the row reorders.
  • Open ⚖️ Ranking weights to see and adjust the three numbers driving the score formula.

Limitations

  • Data is synthetic and small (8 members, 33 titles) — results are illustrative, not statistically valid.
  • The prototype does not attempt to prove that steering engagement actually lowers churn.
  • Grounding uses a static table and a keyword lookup, not live rights data or semantic search.
